Manage states

Usage: missouri state [OPTIONS] <COMMAND>

Commands:
  add   Add a new state
  help  Print this message or the help of the given subcommand(s)

Options:
  -C <DIRECTORY>                 Change to this directory before doing anything
      --config-dir <CONFIG_DIR>  Name of the config directory [default: .missouri]
  -h, --help                     Print help
