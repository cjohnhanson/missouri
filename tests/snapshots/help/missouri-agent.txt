Agent evaluation commands

Usage: missouri agent [OPTIONS] <COMMAND>

Commands:
  eval  Run an agent evaluation
  pass  Record a passing verdict (called by the agent)
  fail  Record a failing verdict (called by the agent)
  help  Print this message or the help of the given subcommand(s)

Options:
  -C <DIRECTORY>                 Change to this directory before doing anything
      --config-dir <CONFIG_DIR>  Name of the config directory [default: .missouri]
  -h, --help                     Print help
